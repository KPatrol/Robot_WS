━━━━━━━━━━━━━━━━━

ESP32-S3 → BTS7960 #1 (FR) Logic:

  GPIO 16 → LPWM  : BLUE wire (with label "FL")
  GPIO 17 → R_EN  : GREEN wire (with label "FL")
  GPIO 18 → L_EN  : WHITE wire (with label "FL")
  5V      → VCC   : RED wire (thick)
  GND     → GND   : BLACK wire (thick)

Power Wiring:
━━━━━━━━━━━━━
  12V+ → BTS7960 B+: RED wire (very thick, 16-18 AWG)
  12V- → BTS7960 B-: BLACK wire (very thick, 16-18 AWG)

Motor Wiring:
━━━━━━━━━━━━━
  BTS7960 M+ → Motor: Use motor's original RED wire
  BTS7960 M- → Motor: Use motor's original BLACK wire

  13. SAFETY & BEST PRACTICES
================================================================================

Power Safety:
━━━━━━━━━━━━━
  ⚠️ Connect power LAST (after all logic connections verified)
  ⚠️ Use fuse or circuit breaker on 12V supply (5A rating)
  ⚠️ Verify polarity before powering on (12V+ to B+, 12V- to B-)
  ⚠️ Don't reverse motor while at full speed (add delay in code)

Wiring Best Practices:
━━━━━━━━━━━━━━━━━━━━━
  ✓ Use proper wire gauge (16-18 AWG for motor power)
  ✓ Keep logic wires (GPIO) separate from power wires (reduce noise)
  ✓ Use ferrule terminals for secure screw connections
  ✓ Test continuity with multimeter before powering on
  ✓ Add capacitors (100µF-1000µF) near BTS7960 B+/B- for noise reduction

Testing Workflow:
━━━━━━━━━━━━━━━━━
  1. Wire all logic connections (GPIO, VCC, GND)
  2. Upload and test code WITHOUT 12V power (drivers won't spin motors yet)
  3. Verify Serial communication and command response
  4. Power off, connect 12V power
  5. Start with low speed (SPD:50) and test each motor individually
  6. Gradually increase speed and test combinations

Motor Protection:
━━━━━━━━━━━━━━━━━
  ✓ Add 200ms delay when changing motor direction (prevents H-bridge shoot-through)
  ✓ Implement soft-start (gradually increase PWM) for mechanical wear reduction
  ✓ Monitor current with R_IS/L_IS pins (optional, for overload detection)
