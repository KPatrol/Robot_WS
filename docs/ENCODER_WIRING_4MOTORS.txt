================================================================================
  1. MOTOR ENCODER PINOUT (JGA25-370)
================================================================================

Dựa trên hình ảnh của connector 6 chân:

┌─────────────────────────────────────────────────────────────────┐
│                    MOTOR ENCODER CONNECTOR                      │
│                    (6 pins - White connector)                   │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   Pin Order (từ trên xuống dưới khi nhìn từ sau motor):        │
│                                                                 │
│   Pin 1: M1 Motor -      │ BLACK (thick) │ → BTS7960 M-        │
│   Pin 2: GND Encoder     │ BLACK (thin)  │ → ESP32 GND         │
│   Pin 3: Fase A Encoder  │ YELLOW        │ → ESP32 GPIO (INT)  │
│   Pin 4: Fase B Encoder  │ GREEN         │ → ESP32 GPIO (INT)  │
│   Pin 5: 3.3V/5V Encoder │ RED (thin)    │ → ESP32 3.3V        │
│   Pin 6: M1 Motor +      │ RED (thick)   │ → BTS7960 M+        │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

Wire Colors:
━━━━━━━━━━━━
  BLACK (thick) = Motor negative (M-)
  BLACK (thin)  = Encoder GND
  YELLOW        = Encoder Fase A (Phase A)
  GREEN         = Encoder Fase B (Phase B)
  RED (thin)    = Encoder VCC (3.3V or 5V)
  RED (thick)   = Motor positive (M+)

⚠️ QUAN TRỌNG: Phân biệt dây THICK (dày) và THIN (mảnh)!
   - Dây THICK là dây nguồn motor (dòng cao)
   - Dây THIN là dây tín hiệu encoder (dòng thấp)

================================================================================
  6. ENCODER SPECIFICATIONS
================================================================================

JGA25-370 Motor Encoder:
━━━━━━━━━━━━━━━━━━━━━━━━━
  - Type: Hall Effect / Magnetic Encoder
  - PPR (Pulses Per Revolution): 11 PPR (at encoder disk)
  - Gear Ratio: 1:34
  - Output shaft PPR: 11 × 34 = 374 PPR
  - With Quadrature Decoding (×4): 374 × 4 = 1496 counts/revolution
  - Operating Voltage: 3.3V - 5V (use 3.3V with ESP32)
  - Output: Digital square wave (Phase A, Phase B)

Resolution at output shaft:
  - 1496 counts per revolution
  - 360° / 1496 = 0.24° per count
  - Very high resolution for position control

================================================================================
  7. POWER CONNECTIONS
================================================================================

ESP32 Power (separate from motor power):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  - Power ESP32 via USB-C or 5V pin
  - ESP32 3.3V pin → All encoder VCC (shared)
  - ESP32 GND → All encoder GND (shared)

⚠️ Important: ESP32 3.3V can provide ~50mA safely
   4 encoders × ~10mA each = ~40mA total (OK)

Motor Power (via BTS7960):
━━━━━━━━━━━━━━━━━━━━━━━━━━
  - Motor wires (thick) connect to BTS7960 M+/M-
  - Do NOT connect motor power wires to ESP32
  - 12V power supply → BTS7960 drivers

================================================================================
  9. SERIAL OUTPUT FORMAT
================================================================================

Program prints every 500ms:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

────────────────────────────────────────────────
Time: 5.5 sec

FR: Count=1234  Rev=0.82  RPM=45.3
FL: Count=1245  Rev=0.83  RPM=46.1
BR: Count=1230  Rev=0.82  RPM=44.8
BL: Count=1240  Rev=0.83  RPM=45.9

Explanation:
  - Count: Raw encoder pulse count (positive = forward, negative = backward)
  - Rev: Number of output shaft revolutions (Count / 1496)
  - RPM: Current speed in revolutions per minute

Serial Commands:
━━━━━━━━━━━━━━━━
  R - Reset all encoder counts to 0
  W - Show wiring guide
  H - Show help

================================================================================
  10. TROUBLESHOOTING
================================================================================

Issue: No encoder counts (always 0)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  → Check encoder VCC connected to 3.3V
  → Check encoder GND connected to ESP32 GND
  → Verify motor is actually spinning
  → Check Phase A wire connected to correct GPIO
  → Measure encoder output with multimeter (should toggle 0-3.3V)

Issue: Counts increase even when motor stopped
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  → Noise on signal lines - add 0.1µF capacitor between signal and GND
  → Use shorter wires for encoder signals
  → Separate encoder wires from motor power wires

Issue: Counts are wrong direction (negative when forward)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  → Swap Phase A and Phase B wires for that motor
  → Or change sign in code: FR_count-- instead of FR_count++

Issue: One encoder not working, others OK
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  → Check GPIO pin for that specific motor
  → Verify both Phase A and Phase B wires connected
  → Test encoder with multimeter
  → Try swapping with known-working encoder

Issue: GPIO 34/35 not responding
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  → GPIO 34, 35 are input-only and have no internal pullup
  → Make sure encoder has proper output drive
  → Add external 10K pullup resistor if needed
