  5. MECANUM WHEEL MOVEMENT COMMANDS
================================================================================

Serial Commands (115200 baud):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

INDIVIDUAL MOTOR CONTROL:
  FR_F, FR_B, FR_S  : Front-Right Forward/Backward/Stop
  FL_F, FL_B, FL_S  : Front-Left Forward/Backward/Stop
  BR_F, BR_B, BR_S  : Back-Right Forward/Backward/Stop
  BL_F, BL_B, BL_S  : Back-Left Forward/Backward/Stop

MECANUM MOVEMENTS:
  F       : Forward (all wheels forward)
  B       : Backward (all wheels backward)
  SR      : Strafe Right (sideways right)
  SL      : Strafe Left (sideways left)
  R       : Rotate Right (clockwise, in-place)
  L       : Rotate Left (counter-clockwise, in-place)
  DR      : Diagonal Forward-Right
  DL      : Diagonal Forward-Left
  S       : Stop all motors

SPEED & SYSTEM:
  SPD:xxx : Set speed (0-255), e.g. SPD:150
  T       : Run automated test sequence (12 tests)
  I       : Show system information
  H       : Show help menu

================================================================================
  6. MECANUM WHEEL KINEMATICS
================================================================================

Movement Pattern Reference:
━━━━━━━━━━━━━━━━━━━━━━━━━━━

FORWARD (F):
  FR: Forward  ↑
  FL: Forward  ↑
  BR: Forward  ↑
  BL: Forward  ↑
  Result: Robot moves straight forward

BACKWARD (B):
  FR: Backward ↓
  FL: Backward ↓
  BR: Backward ↓
  BL: Backward ↓
  Result: Robot moves straight backward

STRAFE RIGHT (SR):
  FR: Backward ↓
  FL: Forward  ↑
  BR: Forward  ↑
  BL: Backward ↓
  Result: Robot moves sideways to the right

STRAFE LEFT (SL):
  FR: Forward  ↑
  FL: Backward ↓
  BR: Backward ↓
  BL: Forward  ↑
  Result: Robot moves sideways to the left

ROTATE RIGHT (R):
  FR: Backward ↓
  FL: Forward  ↑
  BR: Backward ↓
  BL: Forward  ↑
  Result: Robot rotates clockwise (in-place)

ROTATE LEFT (L):
  FR: Forward  ↑
  FL: Backward ↓
  BR: Forward  ↑
  BL: Backward ↓
  Result: Robot rotates counter-clockwise (in-place)

DIAGONAL FORWARD-RIGHT (DR):
  FR: Stop     —
  FL: Forward  ↑
  BR: Forward  ↑
  BL: Stop     —
  Result: Robot moves diagonally forward-right (45°)

DIAGONAL FORWARD-LEFT (DL):
  FR: Forward  ↑
  FL: Stop     —
  BR: Stop     —
  BL: Forward  ↑
  Result: Robot moves diagonally forward-left (45°)

  7. MOTOR DIRECTION INVERSION
================================================================================

In the code, adjust these flags if motors rotate opposite:

#define FR_INVERTED false  // Set true if FR rotates opposite
#define FL_INVERTED true   // Set true if FL rotates opposite (đã đúng)
#define BR_INVERTED false  // Set true if BR rotates opposite
#define BL_INVERTED true   // Set true if BL rotates opposite (assume same as FL)

Testing Process:
━━━━━━━━━━━━━━━━
1. Test BL motor individually: BL_F, BL_B
2. If BL rotates opposite of expected, change BL_INVERTED to opposite value
3. Test F command - all 4 wheels should rotate to move robot forward
4. Adjust individual motor inversion flags until F command works correctly

================================================================================
  9. TESTING PROCEDURE - MECANUM SYSTEM
================================================================================

Step 1: Individual Motor Test
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Upload code and test each motor individually:

  SPD:100
  FR_F    → Front-Right should spin (note direction)
  FR_S
  FL_F    → Front-Left should spin (note direction)
  FL_S
  BR_F    → Back-Right should spin (note direction)
  BR_S
  BL_F    → Back-Left should spin (note direction)
  BL_S

All 4 motors should spin when commanded. If not, check wiring and power.

Step 2: Forward Movement Test
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Test if all 4 wheels rotate correctly for forward motion:

  F       → All 4 wheels should rotate to move robot FORWARD

If robot doesn't move forward:
  - Check which motors are rotating wrong direction
  - Adjust INVERTED flags in code for those motors
  - Re-upload and test again

Step 3: Mecanum Movement Tests
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Once forward works, test other movements:

  B       → Robot moves backward
  SR      → Robot strafes right (sideways)
  SL      → Robot strafes left (sideways)
  R       → Robot rotates right (in-place)
  L       → Robot rotates left (in-place)
  DR      → Robot moves diagonally forward-right
  DL      → Robot moves diagonally forward-left

Step 4: Speed Control Test
━━━━━━━━━━━━━━━━━━━━━━━━
Test different speeds:

  SPD:50   → Set low speed
  F        → Robot should move slowly forward
  S
  SPD:200  → Set high speed
  F        → Robot should move fast forward
  S

Step 5: Automated Test Sequence
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Run full test sequence:

  T        → Runs 12 automated tests (~2 minutes)

Observe all movements and verify robot behaves as expected.

  10. TROUBLESHOOTING - 4 MOTOR SYSTEM
================================================================================

Issue: One or more motors don't work
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  → Verify BTS7960 power LEDs are ON for all drivers
  → Test motors individually (FR_F, FL_F, BR_F, BL_F)
  → Check GPIO connections for non-working motor
  → Measure 12V at each BTS7960 B+/B- terminals

Issue: Robot moves forward when commanded but not straight
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  → One or more motors rotating wrong direction
  → Adjust INVERTED flags in code for specific motors
