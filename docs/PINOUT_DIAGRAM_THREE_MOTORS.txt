  GPIO 17 → FL_R_EN  (Digital Output - Always HIGH)
  GPIO 18 → FL_L_EN  (Digital Output - Always HIGH)

BACK-RIGHT MOTOR (BR) - BTS7960 Driver #3:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  GPIO 9  → BR_LPWM  (PWM Channel 5 - Backward)

PWM CONFIGURATION:
━━━━━━━━━━━━━━━━━

  Resolution: 8-bit (0-255)

  Channel 1: FR_LPWM (GPIO 5)
  Channel 2: FL_RPWM (GPIO 15)
  Channel 3: FL_LPWM (GPIO 16)

  Channel 5: BR_LPWM (GPIO 9)

  5. SERIAL COMMANDS - THREE MOTORS
================================================================================

Serial Commands (115200 baud):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

INDIVIDUAL MOTOR CONTROL:
  FR_F  : Front-Right Forward
  FR_B  : Front-Right Backward
  FR_S  : Front-Right Stop
  
  FL_F  : Front-Left Forward
  FL_B  : Front-Left Backward
  FL_S  : Front-Left Stop
  
  BR_F  : Back-Right Forward
  BR_B  : Back-Right Backward
  BR_S  : Back-Right Stop

ALL MOTORS TOGETHER:
  F     : All Forward (robot moves forward)
  B     : All Backward (robot moves backward)
  S     : All Stop

ROTATION:
  R     : Rotate Right (FR+BR backward, FL forward)
  L     : Rotate Left (FR+BR forward, FL backward)

SPEED CONTROL (0-255):
  SPD:150   : Set speed to 150 (medium)
  SPD:255   : Set speed to 255 (max)
  SPD:100   : Set speed to 100 (slow)

SYSTEM:
  T     : Run automated test sequence
  I     : Show system info
  H     : Show help menu
