==========================================================================
                    THÔNG SỐ KỸ THUẬT
==========================================================================

ESP32-S3 WROOM-1:
├─ Voltage: 3.3V logic
├─ GPIO Output: 3.3V (tương thích 5V input với resistor)
├─ PWM Channels: 16 (LEDC)
├─ PWM Frequency: 1Hz - 40MHz (test dùng 5kHz)
└─ PWM Resolution: 1-16 bit (test dùng 8-bit = 0-255)

BTS7960 Driver:
├─ Logic Voltage: 3.3V - 5V
├─ Motor Voltage: 5.5V - 27V
├─ Max Current: 43A (continuous)
├─ PWM Frequency: 25kHz max (khuyến nghị 5-20kHz)
└─ Control Method: Dual PWM + Dual Enable

Motor JGA25-370:
├─ Voltage: 12V DC
├─ No-load Speed: ~165 RPM
├─ No-load Current: ~200mA
├─ Stall Current: ~2.5A
├─ Gear Ratio: 1:34
└─ Encoder: 11 PPR (44 CPR quadrature)
